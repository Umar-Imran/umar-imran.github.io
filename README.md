## Before publishing

Check keyboard navigation, disclosures, skip links, 320px mobile reflow and 200% text enlargement. Confirm all relative links resolve and metadata uses the production origin.

Describe client work by domain. Do not commit client names, private repository links, internal URLs, credentials, customer data or unapproved screenshots. Keep measured outcomes scoped to the work that was actually measured; distinguish individual contribution from platform context.
